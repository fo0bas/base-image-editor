Простой, быстрый, работает офлайн, со встроенным поиском клипартов.

📄 Работа с макетом
Кнопка	Что делает
🆕 Новый макет	Создаёт холст нужного размера (500×500, 1920×1080 и т.д.)
💾 Сохранить	Сохраняет готовое изображение в папку done/
📋 Копировать	Копирует весь холст (фон + рисунки + объекты) в буфер обмена
🎨 Цвет фона	Задаёт цвет фона макета, можно с прозрачностью
⬜ Прозрачный фон	Возвращает фон макета в прозрачное состояние
🖼 Изображения и текст
Действие	Описание
🖼 Изображение	Добавляет картинку на холст
🅣 Текст	Добавляет текст на холст (шрифт, размер, цвет, жирный, курсив)
🖱 Двойной клик по тексту	Открывает редактирование прямо на холсте
⌨️ F2 / ПКМ по тексту	Открывает расширенные настройки текста
⚙️ ПКМ по изображению	Открывает яркость, контраст, насыщенность, поворот, прозрачность
🗂 Слои
Кнопка	Что делает
⬆️ Вперёд	Поднимает объект на один слой выше
⬇️ Назад	Опускает объект на один слой ниже
⏫ На передний	Ставит объект поверх всех
⏬ На задний	Отправляет объект за все остальные
🔄 Трансформация
Кнопка	Что делает
↔️ Отразить гориз.	Отражает объект слева направо
↕️ Отразить верт.	Отражает объект сверху вниз
🔄 Повернуть	Поворачивает объект на выбранный угол
🖌 Кисть и ластик
Инструмент	Описание
🖌 Кисть	Открывает окно настроек (цвет + толщина 1–30 px), после ОК можно рисовать
🧽 Ластик	Открывает окно настроек (толщина 10–50 px), стирает только линии кисти
🎯 Поведение	Линии кисти всегда рисуются поверх всех объектов
↩️ Ctrl+Z	Отменяет последний штрих
⌨️ Горячие клавиши объектов
Комбинация	Действие
Ctrl+C	Копировать выделенный объект
Ctrl+X	Вырезать выделенный объект
Ctrl+V	Вставить объект из буфера
Ctrl+D	Создать копию выделенного
Ctrl+A	Выделить сразу все объекты
Ctrl+Z	Отменить последнее действие
Del / Backspace	Удалить выделенный объект
Esc	Снять выделение
🖱 Перемещение и масштаб
Действие	Описание
ЛКМ + перетаскивание	Двигает объект по холсту
Угловые ручки	Изменяют размер объекта
Ctrl + клик	Добавляет объект к выделению
Ctrl + колесо	Приближает или отдаляет холст
Средняя кнопка / колесо	Прокручивает холст без изменения масштаба
📁 Хранилище
Действие	Описание
📂 Вкладка «Хранилище»	Библиотека всех сохранённых картинок
➕ «+ Папка»	Создаёт новую папку внутри save/
🖱 ПКМ по папке	Открыть или удалить папку
🖱 ПКМ по картинке	Удалить файл
👆 Клик по картинке	Добавляет её на холст
🔍 Поиск клипартов
Элемент	Описание
🔎 Строка «Найти»	Ищет клипарты через Clipart.Free
🏷 Категория	Фильтр по тематике (животные, природа, люди...)
🖼 4 плитки в ряд	Постраничный показ результатов
⬅️➡️ «Назад» / «Вперёд»	Переход между страницами
👆 Клик по превью	Скачивает полный PNG и вставляет на холст
ℹ️ Справка
Элемент	Описание
ℹ️ Кнопка «i» слева внизу	Открывает окно со всеми горячими клавишами
📖 Кнопка «Справка» рядом	Делает то же самое
💡 Прочее
Функция	Описание
📥 Drag & Drop	Перетащите файл из проводника прямо на холст
📸 Скриншот	Win+Shift+S → Ctrl+V в редакторе
🔤 Свои шрифты	Положите .ttf / .otf в папку font/
⚙️ Автосоздание папок	font/, save/, done/ создаются при первом запуске
🚀 Быстрый старт
bash
# 1. Клонировать репозиторий
git clone https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python main.py
📦 Требования
Python 3.8 – 3.12

PyQt5 ≥ 5.15

certifi ≥ 2023.7 (для поиска клипартов)

Windows / macOS / Linux

📂 Структура проекта
text
project/
├── main.py             # Основной файл
├── requirements.txt    # Зависимости
├── icon.png            # Иконка приложения
├── icon.ico            # Иконка для Windows (опционально)
├── font/               # Свои шрифты (.ttf / .otf)
├── save/               # Локальная библиотека (создаётся автоматически)
└── done/               # Сохранённые результаты (создаётся автоматически)
