📄 Работа с макетом
«Новый макет» — позволяет создать макет нужного размера (например, 500×500 или 1920×1080).

«Сохранить» — сохраняет готовое изображение в папку done/.

«Копировать» — копирует весь холст (фон + рисунки + объекты) в буфер обмена, чтобы вставить в другую программу.

«Цвет фона» — задаёт цвет фона макета, можно выбрать с прозрачностью.

«Прозрачный фон» — возвращает фон макета в прозрачное состояние.
🖼 Изображения и текст
«Изображение» — добавляет картинку на холст.

«Текст» — добавляет текст на холст (шрифт, размер, цвет, жирный, курсив).

Двойной клик по тексту — открывает редактирование прямо на холсте, можно писать и стирать.

F2 или ПКМ по тексту — открывает расширенные настройки текста.

ПКМ по изображению → «Настройки изображения» — открывает яркость, контраст, насыщенность, поворот, прозрачность.

🗂 Слои
«Вперёд» — поднимает объект на один слой выше.

«Назад» — опускает объект на один слой ниже.

«На передний» — ставит объект поверх всех.

«На задний» — отправляет объект за все остальные.

🔄 Трансформация
«Отразить гориз.» — отражает объект слева направо.

«Отразить верт.» — отражает объект сверху вниз.

«Повернуть» — поворачивает объект на выбранный угол.

🖌 Кисть и ластик
«Кисть» — открывает окно настроек (цвет и толщина 1–30 px), после ОК можно рисовать по холсту.

«Ластик» — открывает окно настроек (толщина 10–50 px), стирает только линии кисти.

Линии кисти всегда рисуются поверх всех объектов.

Ctrl+Z — отменяет последний штрих.

📦 Объекты (горячие клавиши)
Ctrl+C — копирует выделенный объект.

Ctrl+X — вырезает выделенный объект.

Ctrl+V — вставляет объект из буфера.

Ctrl+D — создаёт копию выделенного объекта.

Ctrl+A — выделяет сразу все объекты.

Ctrl+Z — отменяет последнее действие.

Del / Backspace — удаляет выделенный объект.

Esc — снимает выделение.

🖱 Перемещение и масштаб
ЛКМ + перетаскивание — двигает объект по холсту.

Угловые ручки — изменяют размер объекта.

Ctrl + клик — добавляет объект к выделению.

Ctrl + колесо мыши — приближает или отдаляет холст.

Средняя кнопка или колесо — прокручивает холст без изменения масштаба.

📁 Хранилище
Вкладка «Хранилище» — библиотека всех сохранённых картинок.

«+ Папка» — создаёт новую папку внутри save/.

ПКМ по папке — открыть или удалить папку.

ПКМ по картинке — удалить файл.

Клик по картинке — добавляет её на холст.

🔍 Поиск клипартов
Строка «Найти» — ищет клипарты через Clipart.Free.

Категория — фильтр по тематике (животные, природа, люди и т.д.).

4 плитки в ряд — постраничный показ результатов.

«<- Назад» / «Вперёд ->» — переход между страницами.

Клик по превью — скачивает полный PNG и вставляет на холст.

ℹ️ Справка
Кнопка «i» слева внизу — открывает окно со всеми горячими клавишами и функциями.

Кнопка «Справка» рядом с ней — делает то же самое.

💡 Прочее
Drag & Drop — перетащите файл изображения из проводника прямо на холст.

Скриншот — нажмите Win+Shift+S, затем Ctrl+V в редакторе — скриншот появится на холсте.

Свои шрифты — положите .ttf или .otf файлы в папку font/, они появятся в списке шрифтов.

Автосоздание папок — font/, save/, done/ создаются автоматически при первом запуске.
